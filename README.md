# ТВ Витрина — фото и видео с iPhone на Android TV

Приложение для телевизора (Philips и любой другой Android TV / Google TV), которое
поднимает на телевизоре маленький веб-сервер. На iPhone ничего ставить не нужно:
открываете Safari, вводите адрес с экрана телевизора — и получаете страницу с
выбором фото/видео из галереи, загрузкой и пультом управления.

**Почему так, а не «приложение на iPhone»:** чтобы поставить своё приложение на
iPhone, нужен Mac с Xcode, Apple ID и переподписывание каждые 7 дней. Safari
снимает эту проблему полностью — интерфейс всё равно ваш, никакой рекламы и
никаких ограничений на формат.

---

## Что умеет

- Отправка фото и видео из галереи iPhone прямо в браузере, с прогрессом загрузки.
- Файл лежит **на телевизоре**, а не стримится по воздуху — поэтому перемотка
  мгновенная, а качество не режется. Никакого перекодирования.
- Видео играет через ExoPlayer (Media3): H.264, HEVC/H.265, VP9, AV1, MKV, MOV —
  всё, что умеет железо самого телевизора.
- Пульт на телефоне: play / pause / перемотка ползунком / ±10 сек / следующий /
  предыдущий / без звука / повтор.
- Слайдшоу с настраиваемой паузой.
- Галерея с миниатюрами, удаление по одному и «очистить всё».
- Управление и с обычного пульта телевизора (OK — пауза, влево/вправо — перемотка).
- mDNS/Bonjour-регистрация сервиса `_displaystream._tcp` — на случай, если позже
  захотите написать нативный iOS-отправитель.
- HTTP Range (206 Partial Content) на раздаче файлов — можно открыть их и из VLC
  или любого другого плеера в сети.

## Шаг 1. Получить APK

### Вариант А — без компьютера, через GitHub (рекомендую)

1. Заведите бесплатный аккаунт на github.com (можно прямо с iPhone).
2. Создайте новый **приватный или публичный репозиторий**, например `tvcast`.
3. Загрузите в него содержимое этого архива (кнопка «Add file → Upload files»,
   удобнее это сделать с компьютера, но и с телефона возможно).
4. Откройте вкладку **Actions** — сборка `Сборка APK` запустится сама.
5. Через 3–5 минут:
   - готовый файл будет в разделе **Releases → latest → `app-debug.apk`** —
     это прямая ссылка, её можно открыть прямо на телевизоре;
   - либо во вкладке Actions → сборка → **Artifacts → TVCast-APK**.

Ничего устанавливать локально не нужно — APK собирается на серверах GitHub бесплатно.

### Вариант Б — Android Studio

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Нужны JDK 17 и Android SDK 34. Проект открывается в Android Studio как есть.

## Шаг 2. Установить APK на телевизор Philips

1. На телевизоре: **Настройки → Настройки устройства → Об устройстве** →
   несколько раз нажмите **Сборка**, пока не появится «Вы стали разработчиком».
2. **Настройки → Настройки устройства → Безопасность и ограничения →
   Неизвестные источники** → разрешите для того приложения, из которого будете
   устанавливать (например, для браузера или для Downloader).
3. Установите на телевизор приложение **Downloader** (есть в Google Play),
   введите в нём прямую ссылку на `app-debug.apk` из релиза GitHub — оно скачает
   и предложит установить.
   Альтернатива: скинуть APK на флешку и открыть её через любой файловый менеджер
   (например, X-plore или File Commander).
4. После установки приложение появится в списке приложений с названием
   **ТВ Витрина**.

> Официальная инструкция Philips по установке сторонних APK:
> https://tv-sound-monitors.philips.com/s/article/How-to-install-a-third-party-app-APK-on-a-Philips-Android-TV-2015-and-newer-1720105991912

## Шаг 3. Пользоваться

1. Телевизор и iPhone — в одной сети Wi-Fi (одна и та же точка доступа, не
   гостевая сеть).
2. Запустите **ТВ Витрину** на телевизоре. На экране появится адрес вида
   `192.168.1.42:8080` и QR-код.
3. На iPhone наведите камеру на QR-код (или введите адрес в Safari вручную).
4. Нажмите «Фото и видео», выберите файлы — они загрузятся и сразу появятся на
   экране телевизора.
5. Добавьте страницу на домашний экран iPhone («Поделиться → На экран Домой») —
   получится ярлык, неотличимый от приложения.

Пока идёт загрузка большого видео, не блокируйте экран телефона — Safari
приостанавливает передачу в фоне.

## Ограничения, о которых честно стоит знать

- Файлы физически копируются на телевизор, в память приложения. Свободное место
  видно в шапке веб-страницы; кнопка «Очистить всё» освобождает его.
  Если внутренней памяти мало, отправляйте видео порциями и удаляйте после просмотра.
- Скорость ограничена Wi-Fi. На 5 ГГц обычно 20–50 МБ/с: минута 4K-видео с iPhone
  (~350 МБ) уезжает за 10–20 секунд.
- Safari при выборе из «Фото» конвертирует HEIC-снимки в JPEG. Это не потеря
  качества уровня «видно глазом», но если хотите строго оригинал — сначала
  сохраните файл в приложение «Файлы» и отправляйте кнопкой «Файлы».
- Приложение должно быть открыто на телевизоре: пока оно свёрнуто, Android может
  выгрузить сервер.
- APK подписан отладочным ключом. Для домашнего использования этого достаточно.

## Как устроено (для доработки)

```
app/src/main/java/com/tvcast/receiver/
  App.kt            — инициализация хранилища
  CastState.kt      — общее состояние + список команд (StateFlow / SharedFlow)
  MediaRepo.kt      — файлы, миниатюры, MIME, потоковое сохранение
  WebServer.kt      — Ktor CIO: HTTP + WebSocket, загрузка, раздача с Range
  ServerService.kt  — foreground-сервис, держит сервер и mDNS
  NsdHelper.kt      — регистрация _displaystream._tcp через NsdManager
  MainActivity.kt   — экран: ExoPlayer, показ фото, слайдшоу, пульт ТВ
  QrGen.kt          — QR-код с адресом сервера
  NetUtils.kt       — определение локального IP
app/src/main/assets/web/  — страница-пульт, которая открывается в Safari
```

### HTTP API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/` | веб-пульт |
| GET | `/api/state` | текущее состояние (JSON) |
| POST | `/api/cmd` | команда: `show`, `play`, `pause`, `toggle`, `stop`, `seek`, `seekRel`, `next`, `prev`, `slideshow`, `mute`, `repeat`, `delete`, `clear` |
| POST | `/api/upload?show=0` | multipart-загрузка файлов |
| GET | `/media/{id}` | сам файл, с поддержкой Range / 206 |
| GET | `/thumb/{id}` | миниатюра JPEG |
| DELETE | `/api/media/{id}` | удалить файл |
| WS | `/ws` | состояние в реальном времени + приём команд |

Порт по умолчанию — `8080` (константа `WebServer.PORT`).

### Если позже понадобится нативное iOS-приложение

Сервис уже публикуется в сети как `_displaystream._tcp`, а весь протокол —
обычные HTTP и WebSocket. Sender на Swift нужно будет собрать из `NWBrowser`
(поиск), `URLSession` (multipart-загрузка) и `URLSessionWebSocketTask` (команды);
в `Info.plist` понадобятся `NSLocalNetworkUsageDescription`,
`NSBonjourServices` со значением `_displaystream._tcp` и
`NSPhotoLibraryUsageDescription`.
